# 📚 StudyTrack

## ¿Qué es?

StudyTrack es un MVP diseñado para estudiantes de grado 11° que permite analizar algunos hábitos diarios y recibir recomendaciones para organizar mejor su tiempo.

## Problema

En nuestro análisis encontramos relaciones importantes entre hábitos como las horas de estudio, las horas de sueño y el rendimiento académico.

## Usuario

Estudiantes de grado 11°.

## Entrada

El usuario introduce:

* Horas de estudio.
* Horas de sueño.
* Tiempo de pantalla.
* Práctica deportiva.

## Proceso

La aplicación analiza los hábitos mediante un sistema de puntuación de 0 a 4.

Cada hábito favorable suma un punto.

## Salida

La aplicación muestra:

* Puntuación.
* Nivel general.
* Recomendaciones.
* Gráfica.

## Valor

Ayuda al estudiante a identificar hábitos que puede mejorar y a organizar mejor su tiempo.

## Tecnologías

* Python
* Streamlit
* GitHub
